Here’s an explanation of each table in your n8n database schema, based on standard n8n (and some enterprise) setups. Some tables are core to n8n, while others are related to advanced features like annotation, test automation, or multi-user/project support.

Table-by-Table Explanation
Core Workflow Tables
workflow_entity: Stores workflow definitions (nodes, connections, settings, etc.).
workflow_history: Keeps a history of workflow changes for audit/versioning.
workflow_statistics: Aggregated statistics about workflow executions (success, failure, duration, etc.).
workflows_tags: Many-to-many mapping between workflows and tags.
Execution & Data Tables
execution_entity: Stores metadata about each workflow execution (status, timestamps, workflow reference).
execution_data: Stores the input/output data for each execution (can be large blobs).
execution_metadata: Additional metadata for executions (custom fields, etc.).
execution_annotations: Stores annotations (comments, notes) added to executions.
execution_annotation_tags: Tags assigned to execution annotations.
User & Auth Tables
user: Stores user accounts.
user_api_keys: API keys for users (for programmatic access).
invalid_auth_token: Stores invalidated tokens (for security/revocation).
auth_identity: Identity provider records for users (SSO, OAuth, etc.).
auth_provider_sync_history: Tracks synchronization events with external auth providers.
Credentials & Sharing
credentials_entity: Encrypted credentials for external services.
shared_credentials: Which users have access to which credentials.
shared_workflow: Which users have access to which workflows.
Tagging & Organization
tag_entity: Tag definitions.
annotation_tag_entity: Tag definitions specifically for annotations.
folder: Folders for organizing workflows/credentials.
folder_tag: Tags assigned to folders.
Webhooks & Variables
webhook_entity: Stores registered webhooks for workflows.
variables: Stores global/environment variables for workflows.
Settings & System
settings: Global n8n settings/configuration.
installed_nodes: Tracks custom nodes installed in the instance.
installed_packages: Tracks npm packages installed for custom nodes.
migrations: Tracks database schema migrations.
Projects & Multi-Tenancy (Enterprise)
project: Project definitions (for multi-project/tenant setups).
project_relation: Relations between projects and other entities (users, workflows, etc.).
event_destinations: Where events (logs, notifications) are sent for a project.
Insights & Analytics (Enterprise)
insights_by_period: Aggregated analytics by period (day, week, etc.).
insights_metadata: Metadata about analytics/insights.
insights_raw: Raw analytics data.
processed_data: Data processed for analytics/insights.
Test Automation (Enterprise)
test_case_execution: Stores executions of test cases.
test_definition: Test case definitions.
test_metric: Metrics collected from test runs.
test_run: Records of test runs.
